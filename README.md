# 🧾 Financial Dashboard in Python

This project is a lightweight, customizable financial reporting dashboard built with **Pandas** and **Matplotlib**.

## Features
- 📈 Monthly revenue trend analysis
- 🔝 Top 5 products by revenue
- 🌍 Revenue distribution by region

## How to Use
1. Add your data in `data/sales_data.csv`
2. Run: `python financial_dashboard.py`
3. View charts in the `output/` folder

## Ideal For
- Small business owners
- E-commerce analytics
- Freelance clients needing monthly reports
